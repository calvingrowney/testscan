# Makenna's Tuna Brand Investigation

This repository documents a student-led investigation into a premium, protein-forward tuna concept for fitness-minded college students and young adults.

Start with [the project roadmap](docs/01-project-roadmap.md). The project is a research exercise first—not a promise to launch a food business.

## Working rule

Makenna is the creative director. Agents accelerate research, create options, and challenge assumptions; they never make the final decision. Every phase records what the evidence said, what the agents recommended, what Makenna chose, and where AI was wrong.

## Folder map

- `docs/` — roadmap, agent playbooks, research standards, portfolio plan
- `templates/` — reusable logs for interviews, decisions, and claim review
- `evidence/` — source notes, interview transcripts/notes, survey exports, supplier research (create as work begins)
- `deliverables/` — approved artifacts only: brief, identity, packaging, site, campaign

## First session

1. Read the roadmap through Gate 1.
2. Create `evidence/` and use the decision log for every consequential choice.
3. Do not name, design, order product, or make fitness/health claims until the relevant gate has been passed.
